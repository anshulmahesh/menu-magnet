Gesture Studio is an illustrative motion study, not a recording of the Lua engine. The bundled script limits each fast input to maxJump = 3 rows by default and suppresses inertial scroll-wheel events; the browser animation exaggerates longer glides for clarity.

Magnetic scrollingTwo touch points travel up or down the trackpad. Each menu-row change produces one subtle haptic-style click and a brief surface pulse.
Submenus and returnPress with two fingers to enter. From inside, flick upward to reach the top, lift, then make a second distinct upward flick to return to the parent menu.
Momentum scrollingA flick is one fast finger movement followed by immediate lift-off. The menu keeps moving afterward; audible clicks continue without repeated finger gestures.
Install locally

Start using Menu Magnet

A Hammerspoon script, not a new trackpad driver or system extension. All you need for the base interaction is Hammerspoon and Accessibility permission.

Download Lua source ↓Full installation guide ↗
01 / REQUIRED

Install Hammerspoon

Use Hammerspoon to run the Lua script. Allow Hammerspoon under macOS System Settings → Privacy & Security → Accessibility.

02 / LOAD

Add the script once

Save MenuMagnet.lua inside ~/.hammerspoon/, add one loader call to your existing init.lua, then reload the configuration.

03 / OPTIONAL

Enable hardware detents

mactic can provide trackpad haptics on supported Macs. Without it, the script can play a quiet system-sound fallback.

One-line loader: add dofile(hs.configdir .. "/MenuMagnet.lua") to your existing ~/.hammerspoon/init.lua. Do not replace your full configuration or load multiple copies of Menu Magnet.
Interaction mapping

Native gestures remain native.

Menu Magnet operates on standard click and scroll events while it owns an accessible menu. You do not need to disable macOS four-finger gestures.

See the full native mapping ↗
Two-finger secondary click

Opens a native context menu; can enter a known submenu while one is open.

Two-finger vertical scroll

Moves across menu items using configurable magnetic thresholds.

One-finger primary click

Native selection is retained. The script follows accessible submenus.

Three- and four-finger swipes

No default remapping. Experimental three-finger back stays off.

Personalise the feel

Fine-tune the experience.

The Lua configuration includes scroll distance, acceleration, speed, cursor behaviour, haptics, submenu handling and hotkeys. Change values in the CONFIG table and reload Hammerspoon.

Open complete settings reference ↗
SENSITIVITY

Magnetic travel

scrollThreshold = 15 and velocitySensitivity = 45 determine how readily navigation advances.

TACTILE

Haptic or sound

hapticEnabled = true, hapticWaveform = 1 and soundFallbackEnabled = true control feedback.

SUBMENU

Edge escape

edgeEscapeToRoot = true uses a distinct second scroll gesture at the submenu edge to return to the root menu.

Supported menu structure depends on the target app's macOS Accessibility implementation. The Finder and Apple Music list-view extensions are not included in this standalone menu-navigation engine.

Menu Magnet · browser-based motion study, not a live macOS input capture. The audio approximates tactile feedback; web pages cannot trigger the Mac trackpad's physical Taptic Engine.
